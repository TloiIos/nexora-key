# 🚀 HƯỚNG DẪN UP CODE LÊN GITHUB (KHÔNG CẦN CÀI ĐẶT GIT)

Vì máy tính của bạn chưa được cài đặt công cụ Git dòng lệnh (`git: Command not found`), bạn có thể sử dụng **2 cách đơn giản dưới đây** trực tiếp bằng giao diện đồ họa cực kỳ dễ dàng.

---

## 💡 CÁCH 1: Tải trực tiếp lên trang web GitHub (Dễ nhất - Không cần cài gì cả)

Bạn có thể tải toàn bộ thư mục web lên GitHub bằng cách kéo thả trên trình duyệt web:

1. **Tạo repository mới trên GitHub:**
   - Truy cập trang web [GitHub.com](https://github.com/) và đăng nhập.
   - Bấm nút **New** (hoặc truy cập [github.com/new](https://github.com/new)).
   - Đặt tên dự án (Ví dụ: `nexora-key`).
   - Chọn chế độ **Public** (Công khai).
   - **QUAN TRỌNG:** Ở phía dưới, tích chọn ô **Add a README file**. (Việc này giúp tạo sẵn một file để kích hoạt nút Upload).
   - Bấm nút **Create repository**.

2. **Kéo thả các file lên:**
   - Tại trang repo vừa tạo, bấm vào nút **Add file** -> Chọn **Upload files**.
   - Mở thư mục dự án `shop` trên máy tính của bạn (`c:\Users\lmod8\Downloads\shop (1)\shop`).
   - **Chọn toàn bộ các file và thư mục** bên trong thư mục này (gồm `index.html`, `about.html`, `admin.html`, `login.html`, thư mục `css`, thư mục `js`, thư mục `data`...).
   - Kéo tất cả và thả vào vùng nhận file trên trình duyệt GitHub.
   - Chờ trình duyệt tải lên toàn bộ (khoảng 30 giây).
   - Cuộn xuống cuối trang bấm nút **Commit changes** để lưu lại.

---

## 💻 CÁCH 2: Sử dụng phần mềm GitHub Desktop (Giao diện trực quan)

Nếu bạn muốn quản lý mã nguồn lâu dài và đẩy cập nhật nhanh chóng sau này:

1. **Tải và cài đặt phần mềm:**
   - Truy cập [desktop.github.com](https://desktop.github.com/) để tải phần mềm về cài đặt.

2. **Liên kết thư mục:**
   - Mở ứng dụng **GitHub Desktop** và đăng nhập tài khoản GitHub của bạn.
   - Vào menu **File** -> Chọn **Add local repository...**
   - Bấm **Choose...** và trỏ đường dẫn tới thư mục dự án của bạn: `c:\Users\lmod8\Downloads\shop (1)\shop`.
   - Bấm **Add repository**. (Nếu phần mềm thông báo thư mục chưa là Git repository, bấm chọn **Create a repository here** rồi điền thông tin và tạo).

3. **Đăng tải (Publish):**
   - Viết ghi chú commit ở góc dưới bên trái (ví dụ: `Initial commit`).
   - Bấm nút **Commit to main**.
   - Bấm nút **Publish repository** ở góc trên cùng để tải code lên GitHub.

---

## 🌐 CÁCH BẬT LINK WEBSITE CHẠY ONLINE (GitHub Pages)

Sau khi code đã được tải lên GitHub thành công theo một trong hai cách trên:

1. Tại Repository trên GitHub, bấm chọn tab **Settings** (Cài đặt).
2. Nhìn danh sách menu bên trái, cuộn xuống chọn mục **Pages**.
3. Tại phần **Build and deployment**:
   - Mục **Branch**: Chọn nhánh **`main`** (hoặc `master`).
   - Thư mục chọn **`/ (root)`**.
   - Bấm nút **Save** (Lưu).
4. F5 tải lại trang sau 1 phút, bạn sẽ thấy đường link trang web màu xanh hiển thị ở đầu trang Pages (Ví dụ: `https://lmod8.github.io/nexora-key/`). Khách hàng của bạn có thể truy cập link này ở bất kỳ đâu!
